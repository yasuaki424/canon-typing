遊び方
  • 表示された英単語を入力して Enter → 正解で砲弾を1発装填（最大5発）
  • 5連続正解で 榴弾 を1発獲得（最大3発）。榴弾は地形を破壊でき、戦車には2倍のダメージ
  • up / down … 砲塔の角度を上げる / 下げる（3°ずつ）
  • forward / back … 戦車を前進 / 後退（戦車2.5台分）
  • fly … ヘリコプターに変身して3秒間上昇（飛行中も攻撃可能）
  • fire … 装填済みの砲弾をまとめてクラスター発射（問題の途中でもOK）
  • bomb … 榴弾を1発発射　／　barrier … 装填済みの弾でバリア展開（1発につき3秒）
  • ボスチャレンジ … 1〜8人で協力して3体のボスに順番に挑戦（倒すと次へ進める）。ドラゴンは触手がまっすぐな弾を防ぐので山なりに撃とう。当てた数でランキング
  • 入力は 半角英数モード（IMEオフ） で。すべて Enter で確定
